# Introdução à Plataforma Java

**O que é o Java:**
O Java é composto por um conjunto bem definido de funcionalidades (features).  

A história da linguagem de programação **Java** começa em 1991, quando a **Sun Microsystems** iniciou o **Projeto Green**, liderado por **James Gosling**, **Mike Sheridan** e **Patrick Naughton**. O objetivo era desenvolver uma linguagem que pudesse ser executada em diversos dispositivos eletrônicos, como TVs interativas e eletrodomésticos inteligentes .

### Desenvolvimento Inicial

A linguagem foi inicialmente chamada de **Oak**, em referência a um carvalho que Gosling via de sua janela. Em 1992, foi apresentado o protótipo *7 (Star-7)*, um controle remoto com interface gráfica touchscreen, acompanhado do mascote **Duke** . No entanto, o projeto não teve sucesso comercial na época.

### Transição para Java

Com o crescimento da internet, a equipe adaptou a linguagem para a web. Em 1995, a linguagem foi renomeada para **Java**, inspirada no café da ilha de Java, e lançada oficialmente. Java permitia a criação de **applets** que podiam ser executados em navegadores, oferecendo interatividade às páginas web .

### Evolução e Popularização

Java rapidamente ganhou popularidade devido à sua portabilidade, com o lema "escreva uma vez, execute em qualquer lugar". Foi amplamente adotada em aplicações web, dispositivos móveis, sistemas embarcados e corporativos. Em 2008, a **Oracle Corporation** adquiriu a Sun Microsystems, tornando-se responsável pelo desenvolvimento do Java .

### Principais Versões

Desde seu lançamento, Java passou por várias atualizações significativas:

- **JDK 1.0** – 1996
- **J2SE 1.2** – 1998
- **Java SE 5.0** – 2004
- **Java SE 8 (LTS)** – 2014
- **Java SE 11 (LTS)** – 2018
- **Java SE 17 (LTS)** – 2021
- **Java SE 21 (LTS)** – 2023
- **Java SE 22** – 2024

### Impacto Atual

Hoje, Java é uma das linguagens de programação mais utilizadas no mundo, presente em aplicações web, sistemas corporativos, dispositivos móveis e muito mais. Sua robustez, segurança e portabilidade continuam a torná-la uma escolha popular entre desenvolvedores e empresas.

### Características da linguagem Java

**Simples**
Java é um linguagem de programação simples e fácil de entender, pois não contém complexidades que existiam em outras LP. A simplicidade era o objetivo do design dos povos Javasoft, pq ele tem que funcionas em dispositivos eletrônicos onde menos memória/recursos estão disponíveis.

**Orientada a objetos**

Isso significa que tudo é escrito em temos de classes e objetos. É necessário ter conhecimento em POO: 

1. Classes e objeto
2. Encapsulamento
3. Abstração
4. Herança
5. Polimorfismo

**Plataforma independente**

O objetivo de design do javasoft people é desenvolver uma LP que funcione em qualquer plataforma, que seria um ambiente de hardware ou software no qual o programa será executado. O código-fonte Java é compilado para bytecode e esse bytecode não está vinculado a nenhuma plataforma.

**Portátil**

O conceito WORA (Write once run anywhere) e o recurso independente de plataforma tornam o Java portátil. Ela pode rodar em qualquer plataforma

**Robusta**

Significa que é capaz de lidar com o encerramento inesperado de um programa

- Ele usa um gerenciamento de memória forte
- Java fornece coleta de lixo automática (uso de recurso de memória)
- Há tratamento de exceção e mecanismo de verificação de tipos em Java.

**Segura**

Problemas como ameaças de vírus, adulteração, espionagem ou representação podem ser tratados ou minimizados usando Java. A construção de aplicativo usando Java também precisa de algum tipo de segurança. A linguagem fornece recursos de segurança e também existem recursos de criptografia e decriptografia para proteger os dados de espionagem e adulteração na internet. 

**Interpretada**

A linguagem Java utiliza compilador e interpretador. Os programas Java são compilados para gerar arquivos de bytecode e a JVM (Java virtual machine) interpreta o arquivo de bytecode durante a execução.

**Multi-thread**

Thead é um subprocesso leve e independente de um programa em execução (ou seja, processo) que compartilha recursos. Multi-threading é nome dados ao processo de vários threads sendo executados simultaneamente.
